# Desktop-2FA 0.11.0 terminal UI

Fresh synthetic PNG/SVG captures using the released app at Desktop commit
6457b420213f9bdc11fa5902b3bad5dc1792a75d (v0.11.0).
All credentials, accounts and codes are synthetic. The Textual headless driver
and a controlled clock produced these screens; PNGs were rendered from SVGs.
The existing capture campaign was run without changing app behavior. Its export
frame title was overridden to identify 0.11.0 rather than the tool’s historical
Unreleased label. This changes the capture frame, not the application screen.
These are terminal captures, not native operating-system windows.

The upstream campaign report covers all nine original captures; this site uses
three. See the complete methods and limitations:
https://github.com/wrogistefan/desktop-2fa/blob/v0.11.0/assets/screenshots/textual-ui/README.md
